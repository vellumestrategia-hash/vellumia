# Véllum AI Implementation Plan

**Goal:** transformar a cópia importada em uma aplicação Véllum AI revisável localmente, preservando seus módulos comerciais maduros.

**Architecture:** Next.js existente com páginas comerciais públicas, catálogo puro compartilhado e configuração de marca runtime. Supabase existente para autenticação e isolamento. Nenhum push ou vínculo operacional com GitHub upstream.

**Tech Stack:** Next.js 16, React 19, TypeScript 6, Tailwind 4, Supabase, Vitest e Playwright.

## Restrições globais

Manter MIT. Não inventar indicadores. Não expor service_role. Preservar RLS, guards e módulos existentes. Valores em centavos. Supabase base sem /rest/v1. Não declarar pronto para produção sem testes autenticados, banco e integrações reais.
